Command Line Intro

By Elias Z. · Steel City Cyber Foundation

The terminal looks scary because it's just text. But it's really just a faster way to talk to your computer. Every security professional uses it daily — and it's a lot less dangerous than it looks, as long as you know the rules.

How to open it

  • Mac: open Terminal (in Applications → Utilities)
  • Windows: open PowerShell, or better, install WSL for a real Linux terminal
  • Linux: Ctrl+Alt+T on most distros

You'll see a prompt like elias@macbook ~ %. That means "ready for your command."

Your first five commands

These are safe. Run them. Nothing bad happens.

pwd          # where am I? (print working directory)
ls           # what's in this folder?
cd Documents # go into the Documents folder
mkdir test   # make a new folder called "test"
cat file.txt # print the contents of file.txt

That's it. You now know navigation. cd is "change directory," and that's most of what people use the terminal for.

The one dangerous command

Here's the rule that keeps you safe: never run a command you don't understand.

There's a famous joke about rm -rf / — it deletes your entire system. It's a joke because it's catastrophic and irreversible. The point isn't to memorize which commands are dangerous. It's to get in the habit of checking before you run anything that came from a random website.

If you're about to run a command you found online, ask: what does this do? If you can't tell, don't run it. There are websites (like explainshell.com) that break down exactly what a command does — paste it in first.

How to learn more without breaking things

  • man command — the manual. man ls shows everything ls can do. Press q to exit.
  • Make a throwaway folder to practice in. mkdir practice && cd practice — break things in there all you want.
  • Tab completion: type the first letters of a file name and press Tab. The terminal fills in the rest. Lifesaver.
  • Up arrow brings back your last command. Edit and rerun it.

Why this matters for security

Lots of security work happens in the terminal — scanning networks, reading logs, checking configs. And on the defense side, most of the "hacking" you see in movies is really just people using the command line. If you want to go further in cybersecurity, this is the tool you'll live in.

If you want a structured, fun way to practice, try OverTheWire Bandit — a free game that teaches Linux commands level by level. It's how a lot of people (including us) got started.

Quick checklist

  • Open the terminal and try pwd, ls, cd
  • Make a practice folder and play around in it
  • Never run commands you don't understand
  • Use man and explainshell.com to check before running
  • Try OverTheWire Bandit when you're ready to level up

You're not going to break your computer by typing ls. Start there.
